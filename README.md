# sourceorigin-xtask

Shared `cargo xtask` checks for the engineering standard that piqueld, sourceorigin and DirkEngine follow: `check-changed` and `test-waits`.

The library lives in [`crates/sourceorigin-xtask`](crates/sourceorigin-xtask), whose README is its documentation. Contributors start with [AGENTS.md](AGENTS.md) and [docs/dev/rust-conventions.md](docs/dev/rust-conventions.md).
