# sourceorigin-standard

The engineering standard of piqueld, sourceorigin and DirkEngine, as code: each rule is enforced by a check rather than stated in prose. Each repository's `cargo xtask` depends on the [`sourceorigin-standard`](crates/sourceorigin-standard) crate and runs its checks, and the crate's README, which lists every rule, is the written standard.

Contributors start with [AGENTS.md](AGENTS.md).
